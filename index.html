Import centre

Bring enriched almanac data back in.

Import ChatGPT's structured JSON, review new and updated records, then commit the data and mark those places as known.

Import enrichment JSON

Choose a JSON file, or paste the JSON text that ChatGPT returned in the chat. A selected file is used first; pasted text is the fallback.

Expected import format

The app expects seb-almanac-enrichment-v1. Each hierarchy level should ideally also be included as a separate place record. You can import either a downloaded JSON file or JSON pasted from ChatGPT.
